# GEMINI_TUNING.md — Surgical UI/UX Adjustments
### Objective
Perform small, targeted interface changes to the existing Sweet Solutions frontend.  
These edits focus on refinement and usability — not redesigns or new features.  
Gemini must always confirm context before changing any files.

---

## 🧭 Prompt 1 — Context Audit & Clarification
> Review the current UI structure (layout, sidebar, dashboard, buttons, typography).  
> Identify visible inconsistencies, spacing issues, or visual elements that don’t match the Refined Whimsy design direction.  
> Ask the user specific questions about intent before changing anything — e.g.:
> - “Do you want to keep or remove this element?”  
> - “Should spacing be adjusted globally or locally?”  
> - “Do you want this style consistent across all pages or just this view?”

---

## 🧩 Prompt 2 — Micro Visual Refinement
> Apply small, clearly approved design changes — for example:
> - Adjust spacing, borders, or padding around sections.  
> - Refine color tones or shadows for better contrast.  
> - Update font sizes or weights for hierarchy clarity.  
> - Modify one-off UI components (badges, buttons, dividers).  
> Keep it minimal and elegant — focus on polish, not overhaul.

---

## 🪞 Prompt 3 — Consistency & Alignment Pass
> Once individual changes are applied, review component spacing and typography across the dashboard for alignment consistency.  
> Standardize margins, gaps, and text hierarchy without altering layout structure.

---

## 🧠 Prompt 4 — Verification & Sign-off
> Ask the user to visually confirm each refined area.  
> Revert any change if the user dislikes the outcome.  
> Confirm the final dashboard matches the Refined Whimsy style with perfect spacing, balance, and harmony.

---

### ⚠️ Rules
- Always **ask before editing.**  
- Never rebuild or rename components.  
- No animations, color system rewrites, or new layout patterns.  
- Maintain all existing functionality and structure.

---

### ✅ Deliverable
A stable, production-safe dashboard that looks visibly tighter, cleaner, and more deliberate, while preserving all existing design logic.
